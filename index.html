Your system is highlighted when it is detected. A greyed button means there is no build for it yet.

First time

  • macOS: open the DMG, drag the app to Applications, then right-click it, choose Open, then Open again (not signed yet).
  • Windows: run the installer; if SmartScreen warns, choose More info, then Run anyway (not signed yet).
  • Linux: make the AppImage executable (chmod +x) and run it, or install the .deb.
  • In Default Configuration, enter your RunPod API key.
  • On RunPod, add an SSH public key (Settings → SSH Public Keys) and a Container Registry Auth login for ghcr.io, then paste its ID in Default Configuration. Steps.
